# Carro ring:bit (português)

Versão em português (pt-PT) da extensão
[ring:bit car](https://github.com/tinkertanker/pxt-ringbitcar) da ELECFREAKS para
o MakeCode micro:bit, usada nos desafios do JuniLab. Tem só os blocos principais
(andar, rodar, virar, travar e velocidade das rodas); os de "mais" (seguidor de
linha e ultrassons) ficaram de fora.

Os nomes no código são os do original, por isso programas feitos com a extensão
em inglês continuam a funcionar com esta.
